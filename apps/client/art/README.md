# Art

Drop finished, cleaned-up PNGs here and the game uses them instead of the code-drawn placeholders. Anything missing falls back to the placeholder. File names:

| File | What | Notes |
|---|---|---|
| `rock.png` `dirt.png` `coal.png` | Terrain fill textures | Seamless. One image spans 4 × 4 cells. |
| `backwall.png` | Cave back wall | Seamless. One image spans 8 × 8 cells. |
| `hearth.png` | Hearth base (no flame) | 2 × 1 cells wide, bottom-aligned. |
| `ladder.png` | One ladder section | 1 × 1 cell, tiles vertically. |
| `mushroom-bed.png` | Mushroom bed | 1 × 1 cell for now. |
| `diffuser.png` | Oxygen diffuser | 1 × 1 cell for now. |
| `survivor.png` | A survivor, facing right | About 1 × 1.5 cells, feet at the bottom edge. |

Prompts for each are in `docs/art-prompts.md`, and the style rules in `docs/art-brief.md`.
